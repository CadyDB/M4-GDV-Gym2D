# M4 Matching Game
Dit is de branch voor de Match game.

Voor deze game had ik inspiratie genomen van een spel waar ik veel van hou genaamd Number match. De main mechanic is zo een beetje hetzelfde alleen hier kan je de kleuren van de tiles veranderen met een +2 score bij elke click. Je hebt de optie om de hele grid die gemaakt is een kleur te maken of je hebt de optie om het een volledige rommel te maken.
